Boat Customizer

Summer Reserach Project

This project was developed as part of a Computer Science research initiative under the mentorship of Dr. Charles Cusack and focused on expanding an existing Android application built with the Unity engine. The goal was to introduce new interactive mini-games that encouraged creativity and visual exploration.

The application was designed to blend artistic expression with interactive technology, challenging us to think beyond traditional app functionality and instead focus on playful, immersive user experiences.

My primary contribution was designing and implementing an interactive boat customization feature. Users could modify the boat’s appearance using sliders and selection pickers, allowing for real-time visual feedback and personalization.

Through this work, I gained hands-on experience with Unity’s UI systems, event-driven interactions, and user input handling, reinforcing my interest in interactive design and creative development within game-engine environments.
