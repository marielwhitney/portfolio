Font Playground

Personal Project

I created Font Playground as an interactive web project that lets users experiment with typography and color combinations in real time. The goal was to design a playful, hands-on space where people can explore fonts visually rather than just viewing static examples, making the experience both creative and engaging.

Built for my ART-105 course, this project focuses on usability and interaction, allowing users to easily test different type styles, adjust visual pairings, and discover combinations that work well together. It emphasizes intuitive controls, immediate feedback, and a clean layout so the interface feels simple, responsive, and fun to use.

Through this project, I explored front-end development and design principles while combining creativity with functionality. Font Playground highlights my interest in interactive design, user experience, and building digital tools that inspire experimentation, creativity, and visual exploration.
